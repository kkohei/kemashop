## 5. ビルド提出の手順(Xcode)

### 5-1. バージョン設定
- Xcode → ターゲット → General
- **Version: 1.0** / **Build: 1**

### 5-2. 本番プッシュ設定(サーバー)
中継サーバーは環境自動判定に対応済みなので **切替不要**(サンドボックス/本番の両方に届く)。
念のため `.env` は `APNS_PRODUCTION=false` のままでOK。

### 5-3. Archive(アーカイブ)
1. Xcode 上部のデバイス選択を **「Any iOS Device (arm64)」** に
2. メニュー **Product → Archive**
3. 完了すると **Organizer** が開く

### 5-4. アップロード
1. Organizer で対象アーカイブを選択 → **Distribute App**
2. **App Store Connect** → **Upload** を選択して進む
3. 自動署名のまま進めてアップロード

### 5-5. App Store Connect でビルドを選択
- アップロード後、数分〜数十分で App Store Connect にビルドが表示される
- アプリのバージョンページで、そのビルドを選択
